# 問題の追加方法

問題は **科目ごとの JSON ファイル**（`data/english.json` / `data/japanese.json` / `data/society.json`）に
登録します。ファイルは「章（デッキ）」ごとに問題（カード）をまとめた構造です。

> いちばん簡単な方法は、問題をテキスト・写真・PDF で送っていただくことです。こちらで下記の形式に変換して登録します。

## データの形（スキーマ）

```jsonc
{
  "subject": "英語",
  "decks": [
    {
      "id": "eng-vocab-01",          // 章のID（半角英数字、重複しないこと）
      "title": "英単語 — 基礎①",      // 章の表示名
      "cards": [
        {
          "id": "e1-1",               // 問題のID（重複しないこと。進捗保存のキーになる）
          "question": "問題文をここに",  // 必須
          "answer": "答えをここに",      // 必須
          "explanation": "解説（任意）", // 任意。省略可
          "image": "assets/images/xxx.png" // 任意。写真問題のとき
        }
      ]
    }
  ]
}
```

### 各項目の説明

| 項目 | 必須 | 説明 |
|------|------|------|
| `id` | ✅ | デッキ・カードの識別子。**一度付けたら変えない**（変えると進捗が別物として扱われます） |
| `question` | ✅ | 問題文 |
| `answer` | ✅ | 答え。一問一答なので自由な文字列でOK（自己採点方式） |
| `explanation` | ー | 解説。あると答え合わせのとき表示されます |
| `image` | ー | 写真問題の画像パス。画像は `assets/images/` に置く |

## 章（デッキ）を追加するとき

`decks` の配列に新しいオブジェクトを足すだけです。`id` は他と重複しないようにします。

## 写真つき問題を追加するとき

1. 画像ファイルを `assets/images/` に置く（例: `assets/images/eng-q01.png`）
2. カードに `"image": "assets/images/eng-q01.png"` を追加する

## 科目そのものを増やすとき

1. `data/manifest.json` の `subjects` に1行追加
   ```json
   { "id": "math", "name": "数学", "color": "#8b5cf6", "emoji": "🔢", "file": "data/math.json" }
   ```
2. `data/math.json` を上記スキーマで新規作成

## 注意点

- JSON の文法に注意（末尾カンマは不可、文字列はダブルクォート）。
- 編集後に文法チェックするには:
  ```bash
  python3 -m json.tool data/english.json > /dev/null && echo OK
  ```
- `id` は進捗（正答率・復習リスト）の保存キーです。既存問題の `id` は変更しないでください。
